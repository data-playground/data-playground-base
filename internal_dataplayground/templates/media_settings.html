Recommendation AI

The Gemini explanation layer adds ~2-3 seconds to recommendation generation and uses your Gemini API quota. Toggle it via the MEDIA_RECOMMEND_AI environment variable in docker-compose.yml: 

environment:
  - MEDIA_RECOMMEND_AI=true   # Enable Gemini explanations
  - MEDIA_RECOMMEND_AI=false  # ML-only (faster, no API cost)
Embedding Status

Embeddings are generated nightly by the life_os_generate_embeddings Airflow DAG. You can also trigger it manually from the Airflow UI at localhost:8080.
